# multi-model-grid-validator

Validation of numerical model values over time and automated nearest-grid matching across multiple ocean and atmospheric models.

**다중 수치모델 3차원 정상값 검증 및 최근접 격자 자동매칭 알고리즘 개발** 개인 목표 프로젝트입니다.

## About

지점 기반 해양·기상 서비스에 사용할 수치모델 격자를 자동으로 지정합니다. Excel의 지점별 위·경도를 읽고, 각 모델에서 반경 **40km** 이내의 후보 중 조건을 통과한 최근접 격자를 선택해 인덱스와 대표값을 CSV로 제공합니다.

이 프로젝트의 **3차원 검증**은 `(time, y, x)`의 시간·수평 격자 검증입니다. 수심·고도 등 수직 레벨을 포함한 `(time, z, y, x)` 자료는 현재 구현의 처리 대상이 아닙니다.

## Highlights

- **시간 검증을 포함한 매칭:** WRF 계열을 제외한 모델은 최초 최대 20개 타임스텝 모두 값 조건을 통과해야 후보가 됩니다.
- **반경 제한 최근접 탐색:** Haversine 거리와 지구 반경 6,371km를 사용해 40km 이내 후보에서 최솟값을 선택합니다.
- **다중 모델 지원:** 해양·파랑·대기 모델을 모델별 설정으로 관리합니다. CWW3의 5개 영역을 포함해 코드에는 15개 처리 항목이 있습니다.
- **WRF 예외 처리:** WRF, WRFdm1, WRFdm2는 시간·값 검증 없이 좌표 기준 최근접 격자만 찾습니다.
- **병렬 처리:** 사용 가능한 모델 항목을 프로세스 풀로 처리하고 입력 지점 순서대로 결과를 합칩니다.
- **부분 실행 지원:** 없는 파일이나 열기·처리 실패 모델을 콘솔에 알리고, 성공한 모델의 결과는 저장합니다.
- **Excel·CSV 연계:** 입력의 기존 열을 유지하며 모델별 결과 열을 추가합니다. CSV 인코딩은 `euc-kr`입니다.

## Quick start

기존 실행 안내의 기준 환경은 **Python 3.10**입니다. 별도 검증 환경과 결과는 아래 Validation에 기록합니다.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python "지점_격자_자동매칭.py"
```

macOS / Linux:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python "지점_격자_자동매칭.py"
```

실행 전에 다음을 준비합니다.

1. 스크립트 옆의 `포인트.xlsx`에 `lon`(경도), `lat`(위도) 열을 작성합니다. 좌표는 도 단위입니다.
2. 스크립트 옆에 `model/` 폴더를 만들고 아래 설정에 맞는 NetCDF 파일을 넣습니다.
3. 실행 후 스크립트 옆의 `포인트지정.csv`와 콘솔의 모델 제외 안내를 확인합니다.

경로는 현재 작업 디렉터리가 아닌 **스크립트 위치**를 기준으로 해석합니다. `multiprocessing`은 Python 표준 라이브러리이므로 별도 설치하지 않습니다. Excel `.xlsx`를 읽기 위해 `openpyxl`이 필요합니다.

## Output

| 열 | 의미 |
| --- | --- |
| 입력의 기존 열 | 원본 지점 정보 유지 |
| `<MODEL>_X` | 선택 격자의 0부터 시작하는 열 인덱스 |
| `<MODEL>_Y` | 선택 격자의 0부터 시작하는 행 인덱스 |
| `result_<MODEL>` | 선택 격자의 첫 타임스텝 값. WRF 계열은 생성하지 않음 |

반경 내에 조건을 통과한 격자가 없으면 해당 지점의 결과는 `NaN`이며 CSV에서는 빈 칸으로 저장됩니다. 모델 자체가 누락되거나 처리에 실패하면 해당 모델의 결과 열 전체가 생성되지 않습니다. 출력에는 선택된 격자의 위·경도나 거리 열이 포함되지 않습니다.

## Validation

검증 명령:

```bash
python -m unittest discover -s tests -v
```

2026-10-14 업로드 준비 시 **합성 자료 기반 테스트 11개를 통과**했습니다. 검증 환경은 Windows, Python 3.13.9, NumPy 2.5.4, pandas 3.0.6, netCDF4 1.7.4, openpyxl 3.1.5입니다. netCDF4의 배열 쓰기에서 NumPy 관련 DeprecationWarning이 발생했지만 테스트는 통과했습니다. 실제 모델 전체를 재실행한 정확도·성능 검증과는 구분합니다.

- 동일 좌표의 거리 0 및 적도 경도 1도 거리 계산.
- 무효인 최근접 격자를 제외하고 다음 유효 격자 선택, 40km 밖 후보 제외.
- 여러 시점 중 한 시점에서 0인 격자 제외 및 첫 시점 대표값 반환.
- 최초 20개 시점만 검사하는 현재 정책, 20개 미만 자료의 처리.
- 1차원·2차원 좌표 및 WRF의 값 검증 생략.
- 파일 누락·열기 실패·지원하지 않는 변수 차원의 실패 반환.
- 모든 모델이 누락된 상태에서 실행 시 원본 지점만 CSV로 저장하는 동작.

기존 예시 CSV는 **17행·44열**이며, 함께 있는 예시 Excel도 17행입니다. 루트의 현재 입력 Excel은 **19행·2열**이므로 기존 CSV를 현재 입력의 재실행 결과로 간주하면 안 됩니다. 예시 CSV의 각 행에는 일부 모델 결과가 비어 있습니다. 이 파일은 출력 형식 참고용이며, 모든 모델의 정상 매칭을 증명하지 않습니다.

설명자료의 ‘1,000개 지점 약 6분’은 기존 자료에 기재된 수치이며 이번 업로드 작업에서 재측정하지 않았습니다.

## Notes

### 현재 정상값 판정의 범위

`is_normal_value()`는 NaN과 0을 제외하고, 값을 문자열로 변환했을 때 `+` 또는 `-`가 들어 있는 값과 `nan`, `NaN`, `None`을 제외합니다. 따라서 **음수와 부호가 포함된 과학적 표기 값도 제외될 수 있으며, 양의 무한대는 통과할 수 있습니다.** 이 규칙은 변수별 물리적 정상 범위 검증을 대신하지 않습니다. 적용 변수에 따라 조건을 검토해야 합니다.

NetCDF 마스크·`_FillValue` 처리를 일반화해 검증한 상태는 아닙니다. 모든 시점이나 수직 레벨을 검증하는 기능도 제공하지 않습니다. 시간 길이가 0인 자료의 정상 처리는 보장하지 않습니다.

### 실행과 데이터 관리

- 반경 40km와 최대 20개 타임스텝은 코드에 고정되어 있습니다. CLI 옵션은 없습니다.
- 모델 변수를 전체 로딩한 후 최초 최대 20개 시점을 검사합니다. 대용량 파일과 병렬 실행은 메모리 사용량을 늘릴 수 있습니다. CWW3 영역들은 같은 파일을 개별 프로세스에서 읽습니다.
- 모든 모델이 실패해도 입력만 담긴 CSV가 생성될 수 있습니다. 파일 생성 여부만으로 성공을 판단하지 말고 결과 열과 콘솔 안내를 확인해야 합니다.
- `missing_models.txt` 저장 코드는 현재 주석 처리되어 있어 오류 안내는 콘솔에만 표시됩니다.
- `euc-kr`로 표현할 수 없는 문자가 입력에 있으면 CSV 저장이 실패할 수 있습니다.
- 모델 원본은 저장소에 포함하지 않습니다. 사용 권한이 있는 데이터를 별도로 준비하십시오.
- 의존성 버전은 고정하지 않았습니다. 검증 당시 버전은 검증 기록에 따로 기재합니다.

### 향후 개선 후보

변수별 유효 범위와 마스크 처리, 반경·시간 조건 설정화, 슬라이스 읽기를 통한 메모리 절감, 선택 격자 좌표·거리 출력, 수직 레벨을 포함한 4차원 검증, 결과 시각화가 개선 후보입니다. 현재 구현된 기능과 구분합니다.

포인트지정.csv
: 포인트.xlsx를 처리한 자료

model 폴더
: 사용할 모델 데이터가 위치
(제출시 용량 문제가 있어, 제출 폴더에는 YES3K, MOHID, SWAN 제외)

#####

1. 폴더/파일 구조
프로그램은 코드 파일이 위치한 폴더를 기준으로 상대경로를 사용합니다.(model 폴더나 포인트.xlsx의 위치를 옳겨서 실행하지 마세요.


2. 입력 데이터(포인트.xlsx) 형식
포인트.xlsx에는 최소한 아래 컬럼이 존재해야 합니다.
lon
lat


3. 출력 데이터(포인트지정.csv)
각 지점에 대해 모델별로 아래 컬럼이 추가됩니다.
<MODEL>_X : 선택된 격자의 X 인덱스(열 방향)
<MODEL>_Y : 선택된 격자의 Y 인덱스(행 방향)
result_<MODEL> : (WRF 계열 제외) 첫 타임스텝의 값
반경 내에 유효 격자가 없으면 해당 모델 컬럼은 NaN으로 기록됩니다.


4. 실행 방법
Python 3.10 기준

필수 패키지(최소):
numpy
pandas
netCDF4
openpyxl

multiprocessing은 Python 표준 라이브러리입니다(별도 설치 불필요).
설치: python -m pip install -r requirements.txt
모델 데이터는 GitHub에 포함되지 않으므로 model 폴더에 별도로 준비하십시오.
상세 모델 설정, 검증 방법 및 현재 제약은 README.md를 참고하십시오.

실행:
1. 포인트.xlsx에 인근 모델 격자를 찾고자 하는 지점의 위경도를 입력해주십시오.
2. python 지점_격자_자동매칭.py 를 실행하십시오.
3. 포인트.xlsx의 각 지점에 대한 모델 결과값인 포인트지정.csv가 생성됩니다.
